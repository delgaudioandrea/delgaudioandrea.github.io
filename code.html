MUSCL2D — 2D shallow water equations solver

A second-order finite-volume solver for the two-dimensional shallow water equations, written in MATLAB. It includes a ready-to-run example of a dam-break wave propagating over a smooth, flat, dry bed, validated against a reference solution.

  • MUSCL-Hancock reconstruction, second order in space and time, with minmod slope limiter
  • Rusanov (local Lax–Friedrichs) numerical flux at cell interfaces
  • Adaptive time step from the CFL condition
  • Bed friction with the Blasius friction factor, computed from the local Reynolds number
  • Wet/dry treatment and reflective wall boundaries
Download the code (.zip, 0.9 MB) ↓

To run the example: unzip, set the folder as the MATLAB current folder and run MUSCL_SWE_2D.m. See README.txt for the main parameters.
